# 공문 도우미

K-에듀파인 공문 작성을 처음부터 끝까지 도와주는 프로그램입니다(경기도교육청).

## 설치 (처음 한 번)

1. **[Releases](https://github.com/ZZombie04/gongmun-helper/releases/latest)에서 `GongmunHelper_Setup_v1.2.3.zip`을 받습니다.**
   이 저장소의 [`공문도우미_설치_v1.2.3.zip`](공문도우미_설치_v1.2.3.zip)도 같은 파일입니다.
2. *(권장)* 받은 zip을 오른쪽 클릭 → **속성** → 아래 **[차단 해제]** 체크 → **확인**.
   이렇게 하면 4번에서 보안 경고 창이 뜨지 않습니다. 건너뛰어도 설치는 됩니다.
3. zip을 오른쪽 클릭 → **모두 압축 풀기**. zip을 연 창에서 바로 실행하지 마세요.
4. 풀린 폴더의 **`설치.bat`** 을 두 번 누릅니다.
   - **"파일 열기 - 보안 경고 · 게시자를 확인하지 못했습니다"** 창이 뜨면 **[실행]**
   - 파란 **"Windows의 PC 보호"** 창이면 **추가 정보 → [실행]**
   - 인터넷에서 받은 서명 없는 프로그램이라 Windows가 처음 한 번 묻는 것입니다.
5. 끝. 작업표시줄 오른쪽 아래 트레이에 **파란 문서 아이콘**이 생기고, 컴퓨터를 켤 때마다 저절로 실행됩니다. 관리자 권한은 필요 없습니다.

## 새 버전

다시 받을 필요가 없습니다. 새 버전이 나오면 트레이에 알림이 뜨고, 누르면 설치됩니다(트레이 아이콘 오른쪽 클릭 → **[업데이트 확인]** 으로도 됩니다). 이때는 보안 경고 창이 뜨지 않고, 설정·프리셋도 그대로 남습니다.

## 설치가 막힐 때

- **스마트 앱 컨트롤**이 켜진 PC(주로 새로 산 Windows 11)는 설치가 막히거나 "제한 모드" 안내가 나옵니다. 설정 → 개인정보 및 보안 → Windows 보안 → 앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤 설정에서 끈 뒤 다시 설치하세요.
- **기관 보안 정책**으로 PowerShell 실행이 막힌 PC는 설치할 때 안내가 나옵니다. 학교 정보 담당자에게 문의하세요.
- 그 밖의 것은 [사용법.txt](사용법.txt) 7번을 보세요.

## 하는 일

1. **공문 작성 도우미** — 기안 창에 붙는 패널 하나에서 처음부터 끝까지:
   - **[작성]** 경기도교육청 기안문 서식 237종을 찾아 한 줄 메모로 채우고, AI가 쓴 초안을 공문 규격으로 정리해 기안 문서(제목·본문)에 바로 넣습니다.
   - **[검사]** 오타·날짜·문체 · **[공개여부]** 판단 · **[표시제]** 공문표시제 표 · **[결재·수신]** 프리셋
2. **수신자 일괄추가** — 행안부유통에서 학교 이름을 붙여 넣으면 검색·선택·추가를 한 번에 합니다.
3. **제출기관 자동추가** — 데이터취합(교육데이터포털)에서 같은 일을 합니다(브라우저 확장).
4. **업무포털 자동 로그인** — 인증서 로그인을 대신 눌러 줍니다.

설치 파일 폴더 [`공문도우미_설치_v1.2.3/`](공문도우미_설치_v1.2.3)에서 압축을 풀지 않고도 내용을 볼 수 있습니다.

## 개인정보와 보안

- 문서 내용·첨부파일·수신자 명단을 인터넷 어디로도 보내지 않습니다. 모든 검사와 판정은 사용자 컴퓨터 안에서 돕니다.
- 새 버전 확인은 시작 뒤 한 번, 그 뒤 6시간마다 이 저장소의 `latest.json` 하나만 읽습니다. 컴퓨터의 문서·설정·이름은 보내지 않고, 설치 파일은 서명(SHA-256)을 맞춰 본 뒤에만 설치합니다.
- 자세한 내용은 사용법.txt 8번을 보세요.
