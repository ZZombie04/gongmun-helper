# 공문 도우미

K-에듀파인 공문 작성을 처음부터 끝까지 도와주는 프로그램입니다(경기도교육청).

- **내려받기**: 이 저장소의 [`공문도우미_설치_v1.2.2.zip`](공문도우미_설치_v1.2.2.zip) 또는 [Releases](https://github.com/ZZombie04/gongmun-helper/releases/latest)의 `GongmunHelper_Setup_v1.2.2.zip` (같은 파일)
- **설치 파일 폴더**: [`공문도우미_설치_v1.2.2/`](공문도우미_설치_v1.2.2) — 압축을 풀지 않고도 내용을 볼 수 있습니다
- **설치**: 압축을 풀고 `설치.bat`을 두 번 누릅니다. 관리자 권한이 필요 없고, 이미 설치된 버전 위에 그대로 설치하면 됩니다(설정·프리셋 유지).
- **사용법**: [사용법.txt](사용법.txt)

## 하는 일

1. **공문 작성 도우미** — 기안 창에 붙는 패널 하나에서 처음부터 끝까지:
   - **[작성]** 경기도교육청 기안문 서식 237종을 찾아 한 줄 메모로 채우고, AI가 쓴 초안을 공문 규격으로 정리해 기안 문서(제목·본문)에 바로 넣습니다.
   - **[검사]** 오타·날짜·문체 · **[공개여부]** 판단 · **[표시제]** 공문표시제 표 · **[결재·수신]** 프리셋
2. **수신자 일괄추가** — 행안부유통에서 학교 이름을 붙여 넣으면 검색·선택·추가를 한 번에 합니다.
3. **제출기관 자동추가** — 데이터취합(교육데이터포털)에서 같은 일을 합니다(브라우저 확장).
4. **업무포털 자동 로그인** — 인증서 로그인을 대신 눌러 줍니다.

## 새 버전 알림

설치된 프로그램은 시작 뒤 한 번, 그 뒤 6시간마다 이 저장소의 `latest.json` 하나만 읽어 새 버전이 있는지 봅니다.
새 버전이 있으면 작업표시줄 트레이에 풍선 알림이 뜨고, 누르면 설치 파일을 내려받아 서명(SHA-256)을 맞춰 본 뒤 설치합니다.
트레이 아이콘 오른쪽 클릭 → [업데이트 확인]으로 직접 확인할 수도 있습니다.

## 개인정보와 보안

- 문서 내용·첨부파일·수신자 명단을 인터넷 어디로도 보내지 않습니다. 모든 검사와 판정은 사용자 컴퓨터 안에서 돕니다.
- 업데이트 확인 때도 버전 안내 파일을 내려받기만 하며, 컴퓨터의 문서·설정·이름은 보내지 않습니다.
