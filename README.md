# 공문 도우미

K-에듀파인 공문 작성을 처음부터 끝까지 도와주는 프로그램입니다(경기도교육청).

## 설치 (처음 한 번)

### 방법 1 — 한 줄 설치 (가장 쉽습니다 · zip 을 받거나 풀 필요가 없습니다)

1. 키보드의 **윈도우 키 + R** 을 누릅니다('실행' 창).
2. 아래 한 줄을 그대로 복사해 붙여 넣고 **Enter**.

```
powershell -NoProfile -Command "[Net.ServicePointManager]::SecurityProtocol='Tls12'; irm https://raw.githubusercontent.com/ZZombie04/gongmun-helper/main/install-online.ps1 | iex"
```

최신 설치 파일을 스스로 내려받아 확인값(SHA-256)을 맞춰 본 뒤 설치합니다. 이렇게 받은 파일에는 '인터넷에서 받음' 표시가 없어서 **차단 해제도, 보안 경고 창도 없습니다.** 학교 통신망이 github 를 막고 있으면 방법 2로 하세요.

### 방법 2 — zip 을 받아 설치

> **⚠ 꼭 이 순서대로 하세요: ① 속성에서 [차단 해제] → ② 모두 압축 풀기 → ③ 설치.bat**

1. **[`공문도우미_설치_v1.4.0_속성에서_차단해제_후_압축풀기.zip`](https://github.com/ZZombie04/gongmun-helper/raw/main/%EA%B3%B5%EB%AC%B8%EB%8F%84%EC%9A%B0%EB%AF%B8_%EC%84%A4%EC%B9%98_v1.4.0_%EC%86%8D%EC%84%B1%EC%97%90%EC%84%9C_%EC%B0%A8%EB%8B%A8%ED%95%B4%EC%A0%9C_%ED%9B%84_%EC%95%95%EC%B6%95%ED%92%80%EA%B8%B0.zip) 을 받습니다.** (이 링크를 누르면 바로 받아집니다. 초록색 **Code → Download ZIP** 으로 받지 마세요)
2. 받은 zip 을 오른쪽 클릭 → **속성** → 맨 아래 **[차단 해제]** 체크 → **확인**.
   - [차단 해제] 칸이 없으면 이미 풀려 있는 것이니 넘어갑니다.
3. zip 을 다시 오른쪽 클릭 → **모두 압축 풀기**. zip 을 연 창에서 바로 실행하지 마세요.
4. 풀린 폴더의 **`설치.bat`** 을 두 번 누릅니다.
5. **"설치가 끝났습니다"** 가 나오고 작업표시줄 오른쪽 아래 트레이에 **파란 문서 아이콘**이 생기면 끝입니다. 컴퓨터를 켤 때마다 저절로 실행됩니다. 관리자 권한은 필요 없습니다.

**왜 [차단 해제] 를 하나요?** 인터넷에서 받은 파일에는 Windows 가 '인터넷에서 받음' 표시를 붙이고, 그대로 풀면 풀린 파일에도 모두 붙습니다. 그러면 보안 경고 창이 뜨고, **스마트 앱 컨트롤이 켜진 PC(주로 새로 산 Windows 11)에서는 `설치.bat` 이 아예 열리지 않습니다.** [차단 해제] 를 하고 풀면 이런 일이 없습니다(스마트 앱 컨트롤을 끌 필요가 없습니다).

2번을 빠뜨리고 풀었더라도 `설치.bat` 이 열리기만 하면 제대로 설치됩니다(v1.4.0 부터). 설치 프로그램이 파일을 새로 써서 넣고, 설치한 뒤 실제로 띄워 보고, 안 되면 이유를 알려 줍니다.
- "파일 열기 - 보안 경고" 창이 뜨면 **[실행]**
- 파란 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → [실행]**

## 잘 안 될 때

| 증상 | 이렇게 하세요 |
| --- | --- |
| `설치.bat` 이 열리지 않는다 | zip 을 **속성 → [차단 해제]** 한 뒤 다시 풀거나, **한 줄 설치**를 씁니다. |
| 설치했는데 트레이 아이콘이 없다 | `설치.bat` 을 한 번 더 누릅니다. 예전 파일을 지우고 새로 넣은 뒤 떠 보고, 안 되면 이유를 적어 줍니다. 백신(V3 · 알약 · Windows 보안)이 막았다면 `%LOCALAPPDATA%\GongmunHelper` 폴더를 예외로 등록하세요. |
| 지우고 싶다 · 깨끗이 다시 깔고 싶다 | 받은 설치 폴더의 **`제거.bat`** 을 누릅니다(설치된 쪽이 망가져 있어도 지워집니다). 그 뒤 `설치.bat`. |
| 그래도 안 된다 | `%LOCALAPPDATA%\GongmunHelper` 의 `host.log` · `install.log` 를 제작자에게 보내 주세요(문서 내용은 들어 있지 않습니다). |

더 자세한 것은 [사용법.txt](사용법.txt) 2번 · 7번 · 9번을 보세요.

## 새 버전

다시 받을 필요가 없습니다. 새 버전이 나오면 트레이에 알림이 뜨고, 누르면 설치됩니다(트레이 아이콘 오른쪽 클릭 → **[업데이트 확인]** 으로도 됩니다). 이때는 보안 경고 창이 뜨지 않고, 설정·프리셋도 그대로 남습니다.

## 하는 일

1. **공문 작성 도우미** — 기안 창에 붙는 패널 하나에서 처음부터 끝까지:
   - **[작성]** 경기도교육청 기안문 학교용·교육청용 서식 383종을 검색하거나 분야 → 업무 → 서식 차례로 골라 한 줄 메모로 채우고, AI가 쓴 초안을 공문 규격으로 정리해 기안 문서(제목·본문)에 바로 넣습니다. **표는 한글 표로 들어갑니다.**
   - **[검사]** 오타·날짜·문체 · **[공개여부]** 판단 · **[표시제]** 공문표시제 표 · **[결재·수신]** 프리셋
2. **수신자 일괄추가** — 행안부유통에서 학교 이름을 붙여 넣으면 검색·선택·추가를 한 번에 합니다. 안 들어간 기관은 **[다시 시도]** · **[이 기관 추가]** 로 바로 처리하고, **[처음부터 다시]** 로 언제든 새로 시작합니다.
3. **제출기관 자동추가** — 데이터취합(교육데이터포털)에서 같은 일을 합니다(브라우저 확장).
4. **업무포털 자동 로그인** — 인증서 로그인을 대신 눌러 줍니다.
5. **장바구니 품의** — 쇼핑몰 장바구니(G마켓·11번가·SSG닷컴·아이스크림몰·쿠팡)에서 고른 상품을 K-에듀파인 품의등록 품목내역에 넣습니다(브라우저 확장).

3·5번은 브라우저 확장 **'공문 도우미'**를 엣지·크롬에 한 번 넣어야 합니다([사용법.txt](사용법.txt) 5번).

## v1.4.0 에서 달라진 것

- **설치**: [차단 해제] 없이 풀어도 설치됩니다. 설치 뒤 실제로 떠 보는 점검을 하고, 안 되면 이유를 알려 줍니다. 다시 설치하면 예전 파일을 지우고 새로 넣습니다. 한 줄 설치가 생겼습니다.
- **제거**: 끝까지 지워집니다. 받은 설치 폴더의 `제거.bat` 으로도 지울 수 있습니다.
- **수신자 일괄추가**: 한 번 실행한 뒤 [수신자 추가 실행] 단추가 사라져 다시 실행할 수 없던 문제를 고쳤습니다. [처음부터 다시] · [다시 시도] · [이 기관 추가].
- **[작성] 탭**: 서식·AI 초안의 표를 글자가 아니라 한글 표로 넣습니다.
- 시작·오류 기록(`host.log`) · 트레이 메뉴 [기록 보기].

설치 파일 폴더 [`공문도우미_설치_v1.4.0/`](공문도우미_설치_v1.4.0)에서 압축을 풀지 않고도 내용을 볼 수 있습니다. zip 확인값(SHA-256): `2451a0ee385c345cf43486a585f9d23411e55359b93393a6f341bf18d6093fd9`

## 개인정보와 보안

- 문서 내용·첨부파일·수신자 명단을 인터넷 어디로도 보내지 않습니다. 모든 검사와 판정은 사용자 컴퓨터 안에서 돕니다.
- 새 버전 확인은 시작 뒤 한 번, 그 뒤 6시간마다 이 저장소의 `latest.json` 하나만 읽습니다. 컴퓨터의 문서·설정·이름은 보내지 않고, 설치 파일은 확인값(SHA-256)을 맞춰 본 뒤에만 설치합니다.
- 기록 파일(`host.log` · `install.log`)에는 시작 시각과 오류 이유만 적히고 문서 내용은 적히지 않습니다.
- 자세한 내용은 사용법.txt 8번을 보세요.
